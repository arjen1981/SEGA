# Implementation Plan: Retro SEGA Visual Theme

**Branch**: `003-retro-sega-theme` | **Date**: 2026-02-16 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/003-retro-sega-theme/spec.md`

## Summary

Transform the SEGA Arcade Graph into an authentic early-'90s SEGA experience through custom SVG node icons (PCB boards, head silhouettes, Japanese building, SEGA wordmark), a CRT scanline overlay, retro typography (Press Start 2P), and SEGA-blue edge styling. Implementation uses vis-network's `shape: "image"` with SVG data URIs for icons, pure CSS for the scanline overlay, and Google Fonts for typography. No new dependencies beyond the Press Start 2P font CDN link.

## Technical Context

**Language/Version**: HTML5, CSS3, JavaScript ES2020+ (ES modules)
**Primary Dependencies**: vis-network v10 (CDN), Press Start 2P font (Google Fonts CDN)
**Storage**: Static JSON files (`nodes.json`, `edges.json`)
**Testing**: QUnit 2.25, browser-based test runner (`tests/index.html`)
**Target Platform**: Modern browsers (Chrome, Firefox, Safari, Edge) — static hosting
**Project Type**: Single static web application
**Performance Goals**: Graph loads and becomes interactive within 3 seconds; theme adds no perceptible delay
**Constraints**: No build pipeline, no server-side processing, all assets must be static-hostable
**Scale/Scope**: ~100 nodes, 6 unique SVG icon types, 1 CSS overlay, 1 font addition
