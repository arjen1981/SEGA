# Implementation Plan: Fix Mobile Layout & Detail Panel

**Branch**: `005-fix-mobile-layout` | **Date**: 2026-02-19 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/005-fix-mobile-layout/spec.md`

## Summary

Fix the mobile (≤767px) experience by converting the detail panel from a full-screen side panel to a half-screen bottom sheet overlay, fixing graph centering after panel close (removing the incorrect 400px desktop panel offset on mobile), and correcting z-index layering so the legend bar doesn't peek through and the search dropdown stays on top. Changes are CSS-only for layout + minor JS adjustments in `getPanelOffset()` and `closeDetailPanel()` for centering logic. Desktop/tablet layouts are unchanged.

## Technical Context

**Language/Version**: HTML5, CSS3, JavaScript ES2020+ (ES modules)
**Primary Dependencies**: vis-network v10 (CDN), Press Start 2P font (Google Fonts CDN)
**Storage**: Static JSON files (`nodes.json`, `edges.json`) — unchanged by this feature
**Testing**: QUnit 2.25, browser-based test runner (`tests/index.html`)
**Target Platform**: Modern mobile browsers (Chrome Android, Safari iOS, Firefox Mobile) + desktop parity
**Project Type**: Single static web application
**Performance Goals**: Detail panel opens within 0.25s; graph re-centers within 1s after panel close
**Constraints**: No build pipeline; no new JS dependencies; changes scoped to ≤767px breakpoint only
**Scale/Scope**: 2 files modified (styles.css, ego-graph.js), 1 file minor update (detail-panel.js)
